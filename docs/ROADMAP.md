- [ ] Solid fixed-step ground vehicle
- [ ] Tire coefficient import
- [ ] Suspension geometry and anti-roll
- [ ] Engine, clutch, gearbox, and drivetrain

- [ ] Lap timing and sectors

- [ ] Motorcycle lean dynamics
- [ ] Fixed-wing aerodynamic coefficients
- [ ] Propeller and turbojet thrust
- [ ] Rocket staging and guidance
- [ ] Re-entry heat and structural integrity

## Milestone 3: Open simulation

- [ ] Open-world streaming
- [ ] Weather and surface moisture
- [ ] Damage and wear
- [ ] Vehicle/track mod browser
- [ ] Setup and telemetry sharing

## Milestone 4: Networking

- [ ] Authoritative dedicated server
- [ ] Offline and sandbox modes
- [ ] Race lobbies
- [ ] Shared telemetry/replay format

- [ ] Raw steering torque output
- [ ] Load-cell pedals
- [ ] H-shifter and clutch
- [ ] Motion rig UDP profiles
